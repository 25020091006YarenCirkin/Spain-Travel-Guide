#  Spain Travel Guide

A responsive travel guide website built with **HTML, CSS, and Bootstrap**. This project provides practical travel information for visitors planning a trip to Spain through a modern blog-style interface.

---

##  Features

- 🇪🇸 Spain travel guide
- 🗺️ Destination recommendations
- 🍽️ Spanish cuisine guide
- 🏛️ History section
- 🗣️ Basic Spanish phrases
- 🖼️ Travel articles with images
- 🏛️ Free museum guide
- 📱 Responsive Bootstrap layout
- 🌙 Theme switching (Light / Dark / Auto)
- 📂 Blog-style navigation

---

##  Technologies

- HTML5
- CSS3
- Bootstrap 5
- JavaScript

---

##  How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
